Third-party licenses bundled in ghcr.io/kerberosmansour/zaprun

This file enumerates the licenses of every component baked into the hardened
ZAP container image. Three categories:

  1. Wolfi base + apk packages installed at build time
  2. OWASP ZAP runtime + Java-bundled dependencies + add-ons
  3. zaprun CLI (Rust binary)

The authoritative per-package license metadata also lives inside the image
at /usr/share/doc/<pkg>/copyright (or equivalent paths under /usr/share/licenses)
for each Wolfi-installed package. The list below is intentionally
human-readable; regenerate from the image with:

    docker run --rm --entrypoint sh ghcr.io/kerberosmansour/zaprun@sha256:<digest> \
      -c 'for d in /usr/share/doc/*/copyright /usr/share/licenses/*/LICENSE*; do
            [ -e "$d" ] && { echo "=== $d ==="; cat "$d"; echo; }
          done'

================================================================================
3. zaprun Rust workspace
================================================================================

The Rust workspace (`crates/zaprun`, `crates/dast-spike`, `crates/dast-spike-rules`)
is MIT-licensed (see LICENSE in the repo root).

The transitive Rust dependency tree is governed by `deny.toml`, which:

   * Allows: MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, CC0-1.0,
            Unlicense, Zlib, Unicode-DFS-2016, CDLA-Permissive-2.0 (for
            webpki-roots), MPL-2.0.
   * Forbids: copyleft licenses (GPL/AGPL/LGPL) — these are not present in
              the resolved graph at the time of writing.

To audit the workspace dependencies from a fresh clone:

    cargo deny check licenses

The full transitive license list is too large to enumerate statically; run
`cargo metadata --format-version=1` to extract it programmatically.
